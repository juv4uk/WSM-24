# WSM-24

**Watch dial as world map. Циферблат як карта світу.**

Азимутальна полярна проєкція Землі з Південним полюсом у центрі,
накладена на **24-годинну шкалу**: 24 години = 360° = довготи.
Годинник працює як модель добового обертання Землі — навігаційний
прилад, а не просто індикатор часу.

> «Ласкаво просимо на борт космічного корабля „Земля“.
> WSM — навігаційний прилад для екіпажу.»

## Концепція

- **24h, не 12h** — повний оберт Землі на циферблаті;
- **Південь у центрі, Гринвіч знизу** — свідомий вибір проти конвенції;
- карта сама є шкалою довгот: подивився на годинник — побачив,
  де зараз сонце, який часовий пояс, де найближчі материки;
- вночі шкала читається проти зоряного неба (зоряний час);
- аналема, нанесена на цю проєкцію, набуває форми, спорідненої
  з яйцем — див. [docs/kinship.md](docs/kinship.md);
- аналогові обчислення: прилад + людський мозок, жодної магії.

## Статус

**PROTOTYPE / ARCHIVAL.** Код у `src/` — це чесна витяжка робочих
ітерацій з дослідницької розмови (див. [docs/provenance.md](docs/provenance.md)),
дві генерації:

- `src/brahmanda/` — проєкція екліптики на південну полярну карту;
- `src/egg/` — порівняння форми проєкції з реальними контурами яєць
  (база EPE, 2221 контур).

Код не зібраний у робочий проєкт і містить відомі недоліки,
описані в provenance. Це архів походження, не реліз.
